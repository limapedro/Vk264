## Error classes logged
1. `MISMATCH NAL0 byte5` — slower/veryslow/placebo SPS differences
2. `MISMATCH NAL1 byte1` / `NAL2 byte5` — superfast..slow PPS/I-slice header differences
3. `oracle EXIT 3221225477` (0xC0000005 access violation) — full-res 1920x1072 CAVLC, non-ultrafast only; ultrafast CAVLC works at full res
4. `MISMATCH NAL COUNT 640-780/602` — 600-frame runs, x264 scene-cut I-frames give more NALs than oracle's fixed keyint schedule
5. Earlier harness bug: 1920x1080 rejected by oracle (exit 2, requires `w%16==0 && h%16==0`); fixed by using 1920x1072 in `tests/fullres/`
